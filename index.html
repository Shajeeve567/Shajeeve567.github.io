01 · solo ● building

BotherMeNot

An event-driven engine that ingests GitHub webhooks and uses an LLM to decide which signals deserve an alert. A router sends each event to exactly one of two BullMQ queues; both evaluators return the same typed result. Tiered Slack delivery with digests and 30-minute escalation.

3 services · 6 shared packages · Zod contracts · idempotent ingestion

TypeScript · Fastify · BullMQ · PostgreSQL · Claude API

02 · team ● deployed · Azure

A multi-tenant client-lifecycle platform as 4 independently deployed .NET 9 microservices. I owned the Workflow Service — the core engine — with a 5-stage gate evaluator and a client-action state machine that fail closed when a dependency is down.

35/69 endpoints · ~60% of backend · 500+ xUnit tests · 10 Kafka event types

C# · .NET 9 · MySQL · Apache Kafka · GitHub Actions

03 · solo ● shipped

ContextHub

A Model Context Protocol server that lets AI coding agents store and recall context across sessions. LLM function calling decides whether each session creates, updates or discards memory; semantic recall runs on pgvector.

12+ MCP tools · 20+ async endpoints · <150 ms over 1,000+ entries

Python · FastAPI · pgvector · SQLAlchemy · MCP · Docker
